# 동화풍 2.5D 재사용 노트

## 새 주제로 옮기는 방법

`demo.js` 상단의 `PALETTE`, `MATERIAL`, `LIGHTING`, `CAMERA`, `RENDERING`을 먼저 정한다. 기본색 일곱 개와 같은 계열의 밝기 변주를 사용한다. `cottage()`를 학교나 가게로, `treeSprite()`를 주제에 맞는 식물로 교체해도 `layer()`의 깊이 순서와 `render(t)`의 공통 시계는 그대로 쓴다. 정적 그림은 `cache()`에서 로드 시 한 번 만들고, 움직이는 부분만 `t`로 계산한다.

## 품질 디렉터의 여섯 결정

## 움직임을 교체할 때

`drawWater()`는 흐르는 붓터치의 위치에 `smooth(saw(t))`를 사용하고 생성·소멸 시 투명도를 0으로 만들어 이음매를 감춘다. `drawSmoke()`도 같은 방식으로 피어오르며 양 끝에서 투명해진다. `drawTrees()`는 뿌리를 기준으로 아주 작은 전단·신축을 적용한다. 구름은 느린 사인 왕복, `drawButterflies()`는 닫힌 타원과 정수 주기 날갯짓을 사용한다. 모든 주기는 정확히 5초 또는 그 정수 분할이어야 한다. 랜덤 값을 렌더 함수 안에서 새로 뽑지 않는다.

## 쓰지 않는 효과

사실적 반사·금속광·선명한 외곽선·DOF·3D 투영·강한 블룸·급격한 카메라 이동은 사용하지 않는다. 그림책의 물감 면과 공간의 층을 해치기 때문이다. 종이결도 프레임마다 바꾸지 않는다. 후처리 노이즈가 움직이면 삽화가 아니라 화면 잡음처럼 보인다.

## 실시간 재생과 MP4 오프라인 렌더링

- 실시간: URL에 시간 인자 없이 열어 `start(render)`로 자동 재생한다. 창 크기와 DPR을 따르며 최대 DPR은 2다. 캐시는 논리 해상도여서 DPR 2에서도 붓칠의 약간 부드러운 질감은 유지된다.
- MP4: 동일한 정적 서버를 사용하고 `?t=0`으로 시작한다. 1920×1080 뷰포트, DPR 1을 고정한다. `window.__demoReady`를 기다린 뒤 `seek(n / fps)`로 정확히 찾아 캡처한다. 30fps이면 n=0~149, 60fps이면 n=0~299만 사용한다. t=5의 중복 프레임을 추가하지 않는다.
- MP4용으로 입자 시드·색·카메라를 바꾸지 않는다. 브라우저 화면과 영상의 재현성을 유지한다. 4K 납품이 필요하면 3840×2160 뷰포트와 `RENDERING.cacheScale: 2`를 함께 사용한다. 기본 캐시는 1080p용이며 캐시 배율 2는 면적 기준 약 네 배의 메모리가 필요하다. 비디오 인코딩은 이 데모 밖의 캡처·인코딩 파이프라인에서 수행한다.
- 주 캔버스는 `willReadFrequently: true`로 생성한다. 같은 프레임을 읽어 캡처할 때 Chrome이 GPU/CPU 경로를 전환하며 만드는 미세한 색상 편차를 피하기 위한 결정이다.

## 실제 검증 기록

2026-11-17, 로컬 Python 정적 서버와 Playwright의 헤드리스 Chrome에서 1920×1080으로 검증했다. t=0·2.5·4.9 화면을 세 차례 렌더링해 직접 확인했고, 두 차례 시각 개선으로 집의 가림·오솔길과 식재 겹침을 수정하고 수목 채색·다리 쐐기돌·최전경 식물을 보강했다.

- `node --input-type=module --check`: 문법 오류 없음. 유일한 import인 `../../shared/runtime.js` 실재 확인. Three.js는 사용하지 않는다.
- 2.5→0→4.999→2.5 순서로 찾아도 2.5초 프레임의 픽셀이 완전히 같음. 4.999→0 경계의 평균 RGB 차이는 약 0.0022/255.
- 콘솔 오류·실패한 요청·외부 네트워크 요청 모두 0건. 1000×1000 창의 16:9 중앙 여백과 스크롤 없음, DPR 2에서 960×540 화면의 1920×1080 backing store 확인.
- 임시 스크린샷과 검사 스크립트는 OS 임시 폴더에만 보관. `preview.png`·`preview.gif` 생성 안 함.
- MP4 인코딩, 4K 캐시 배율 2, 다른 브라우저와 저사양 실기기는 이번 검증 범위에 포함하지 않았다.
