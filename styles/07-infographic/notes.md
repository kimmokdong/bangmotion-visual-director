# 인포그래픽 모션 재사용 안내

공간이나 구조를 보여 주면서 수치를 설명하는 5초 편집형 도해다. 수치는 가상의 예시다. 지도·제목·라벨은 첫 프레임부터 보이고, 치수선·지시선·수치·막대·그림 단위가 0~1.95초에 차례로 그려진 뒤 4.3~4.85초에 함께 걷혀 t=0으로 이어진다. 변경 범위는 이 폴더의 파일이며 공통 시계와 다른 스타일은 수정하지 않는다.

## 품질 디렉터 결정

- **Art**: `PALETTE`, `TYPE`, `buildScene()`에서 관리한다. 종이·도판·흰색의 중성 3색, 잉크(남색), 강조 주황 1색, 하천 청록, 녹지 녹색에 저채도 지붕 2색을 더한다. 강조색은 활성 번호표·초점 링·다리 상판·다리 막대에만 쓴다. 글자는 제목 60px, 큰 수치 68px, 라벨 28px, 본문 24px, 보조 22px의 5단계다. 88px 여백선, 이중 제목 구분선(206·213px), 1288×676 지도 도판, 1424px에서 시작하는 408px 표 열을 지킨다.
- **Material**: `MATERIAL`, `tree()`, `house()`, `bridge()`, `icon()`이 재사용 가능한 평면 벡터 부품이다. 선은 1.5~3px, 면은 단색이다. 지도 라벨은 `.halo`(도판색 6px 외곽선, `paint-order: stroke`)로 등고선·강 위에서도 읽힌다. 도판에는 32px 격자, 위·왼쪽 눈금자, 왼쪽 위 남색 도판 태그를 둔다. 먼 언덕은 같은 곡선을 세로로 눌러 겹친 등고선으로 표현한다.
- **Lighting**: `LIGHTING`은 그림자를 쓰지 않는다. 왼쪽 위 주광을 가정하고 지붕·침엽수·활엽수·벽의 오른쪽 면에만 잉크 14%를 덧칠한다. 줄기·집 기단·다리 교대에 접지선, 강둑에 녹색 윤곽, 강 가운데에 짙은 물길 띠(`band(0.3, 0.7)`)를 둔다.
- **Camera**: `CAMERA`, `render()`에서 제목·표·범례는 고정하고 `#map`(도판 안쪽)만 다리 중심(914, 640)으로 최대 2.2% 확대한다. 0.2~2.4초 smoothstep으로 들어가고 4.25~4.95초에 돌아온다. 도판 clipPath가 확대된 가장자리를 자른다.
- **Rendering**: `index.html`의 SVG viewBox는 1920×1080이며 화면 비율에 맞춰 중앙 정렬한다. 선 그리기는 `draw()`가 `pathLength="1"`과 `stroke-dashoffset`으로 길이를 정규화한다. 시스템 글꼴만 쓰며 CSS animation/transition, 자체 시계, 외부 요청은 없다.
- **QA**: `node scripts/validate-demo.js 07-infographic`, `node scripts/create-contact-sheet.js 07-infographic --times 0,0.5,1,1.5,2,4.6`으로 확인한다. 480×270 축소에서 제목·큰 수치(24 m, 18 m)·번호표가 읽혀야 한다.

## 시간표 (`TIMELINE`)

| 구간 | 내용 |
|---|---|
| 0.05–0.85 | ① 다리: 치수선이 가운데에서 양끝으로 뻗고 틱이 붙는다. 지도와 표의 24가 올라가고 주황 막대가 자란다 |
| 0.15–1.5 | 표 아래 다리 측면도: 아치 → 상판·난간 → 경간 치수 |
| 0.35–1.15 | ② 강: 강 폭 치수와 18 m 칩, 흐름 화살표, 청록 막대 |
| 0.65–1.45 | ③ 집: 지시선 2개, 끝점, 집 그림 단위 2개가 0.15초 간격으로 튀어나온다 |
| 0.95–1.75 | ④ 나무: 지시선, 나무 그림 단위 7개가 0.08초 간격으로 등장하고 개수가 따라 오른다 |
| 1.55–4.3 | 유지. 초점은 다리로 돌아오고 번호표 ①이 1.25초마다 맥동한다 |
| 4.3–4.85 | 모든 정보가 함께 걷힌다(smoothstep). 4.85–5.0은 t=0과 같은 상태 |

`emphasisAt(t)`는 짓는 동안 지금 그려지는 대상을 bell 곡선(반폭 0.3초)으로, 유지 구간에는 다리를 강조한다. 강조는 색을 바꾸지 않고 잉크 원 위 주황 원의 opacity만 바꾼다.

## 새 주제로 바꾸는 순서

1. `buildScene()`의 제목·라벨·범례·표 수치와 `render()`의 카운트업 목표값(24, 18)을 함께 바꾼다. `text()`는 내부 고정 문구용이며 사용자 입력은 이스케이프하거나 `textContent`로 넣는다.
2. 막대는 같은 단위끼리만 같은 축(여기서는 0~30 m)에 놓고, 개수는 그림 단위로 보여 준다. 단위가 다른 값을 한 막대 축에 섞지 않는다.
3. 장면을 바꾸면 `rings`의 중심·타원, 번호표 좌표, `draw()` 지시선 경로를 함께 옮긴다. 레이어 순서는 도판 → 지면·강 → 건물·다리·나무 → 초점 링 → 치수·지시선·라벨이다.
4. 강처럼 띠 모양인 대상은 양쪽 경계를 같은 차수의 베지어 사슬로 만들면 `mix(u)`로 유선과 물길 띠를 얻을 수 있다.
5. 반복 움직임은 5초의 정수 주기만 쓴다. 유선은 대시 주기 18px의 6배(108px), 흐름 화살표는 21px의 3배, 측면도 수면은 22px의 2배, 초점 링은 16px의 2배를 한 루프에 이동한다. 누적 위치나 프레임 수를 쓰지 않는다.

## 사용하지 않는 효과

DOF, 3D 원근, 실사 텍스처·광원, 장식 그라데이션, 글로우, 드롭섀도, 입자 폭발, 화면 흔들림, 글자 모핑을 쓰지 않는다. 카운트업은 쓰지만 제목·지명·범례 같은 읽기 정보는 사라지지 않는다.

## 실시간 재생과 MP4 오프라인 렌더링

- 실시간은 `start(render)`의 기본 자동 재생을 사용한다. 창 리사이즈는 CSS가 처리하며 SVG의 논리 좌표는 고정이다.
- 오프라인은 1920×1080, deviceScaleFactor 1, `?t=0`으로 열고 `window.__demoReady`와 `document.fonts.ready`를 기다린 뒤 프레임마다 `window.__demo.seek(frame / fps)`로 캡처한다. 30fps라면 0~149 프레임만 저장한다.
- MP4 인코딩은 외부 도구에서 H.264, yuv420p, 충분한 비트레이트로 한다. 이 데모에 인코더나 별도 시계를 넣지 않는다. 미리보기 PNG·GIF는 공통 캡처 파이프라인이 만든다.

## 본 구현의 확인 범위

헤드리스 Chrome에서 1920×1080의 0·0.5·1·1.5·2·4.6초와 480×270 축소 화면을 직접 보고 고쳤다. `validate-demo.js` 통과(결정성 차이 0, 루프 이음매 차이 0.015, 콘솔 오류·외부 요청 0건). MP4 인코딩과 다른 운영체제의 시스템 글꼴 조합은 검증하지 않았다.
