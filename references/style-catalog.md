# 그래픽 스타일 도감

8종 고정 스타일. 각 스타일의 실제 데모는 `styles/<id>/index.html`(5초 루프), 세부 규칙은 `styles/<id>/notes.md`, 메타데이터는 `styles/<id>/style.json`.
데모는 모두 같은 장면(강·아치 다리·집 2채·나무·하늘)을 그리므로 차이는 스타일뿐이다.

## 세 축의 구분
스킬 내부에서는 다음 셋을 따로 결정하고 조합한다. 사용자에게는 스타일 이름과 데모만 보여 준다.

- **A. 그래픽 스타일** — 화면의 미술적 특징(색, 형태, 재질, 질감)
- **B. 공간 표현·카메라** — 정사영 아이소 / 정면 2D / 레이어 2.5D / 원근 3D / 탁상 미니어처
- **C. 연출기법** — 장면을 보여 주는 방식(`bangmotion-directing-library.md`)

도감의 8종은 A+B 의 검증된 조합이다. C 는 영상마다 새로 고른다.

## 스타일을 AI가 고를 때 (주제 → 스타일)
위에서부터 처음 맞는 줄을 쓴다.

| 영상의 성격 | 1순위 | 대안 | 이유 |
|---|---|---|---|
| 수치·비율·순위·구조 관계가 핵심 | 07 | 04 | 라벨·치수·위계가 주인공 |
| 디지털 서비스·앱·AI·미래 기술 소개 | 08 | 04 | UI 질감이 주제와 맞음 |
| 3차원 공간 관계·궤도·운동(천체, 지형, 기계 구조) | 02 | 01 | 실제 입체와 카메라 이동이 이해를 도움 |
| 장소의 배치·동선·마을/도시 구조·지도 | 01 | 06 | 왜곡 없는 구조 파악 |
| 특정 장소를 "작은 세계"로 관찰(생태계, 유적, 지역) | 06 | 01 | 모형을 들여다보는 몰입감 |
| 저학년 대상, 이야기·정서·계절 | 03 | 05 | 친근하고 따뜻함 |
| 역사·전래 이야기·수공예 분위기 | 05 | 03 | 손으로 만든 질감 |
| 절차·규칙·개념을 빠르고 명확하게 | 04 | 07 | 군더더기 없는 가독성 |
| 위 어디에도 안 맞음 | 04 | 02 | 가장 범용적 |

예: "지구와 달의 운동" → 02(궤도·입체 관계) / "물의 순환" → 스타일 지정 없으면 01 또는 02 / "우리 반 규칙 소개" → 04 / "인구 변화 통계" → 07.

## 스타일 추가하기
`styles/CONTRACT.md` 를 따르는 새 폴더(`09-…`)를 만들고 `node scripts/validate-demo.js 09-…` → `node scripts/capture-previews.js 09-…` 를 통과시키면 갤러리에 자동으로 나타난다(갤러리는 서버의 `GET /api/styles` 로 `styles/*/style.json` 목록을 읽는다).
