# 템플릿: 개념·과정 설명 (15~40초)

목적: 하나의 개념이나 과정을 3~5단계로 이해시킨다.

| 구간 | 비율 | 내용 | 연출 |
|---|---|---|---|
| 1. 전체 모습 | 15% | 다룰 대상 전체를 한 화면에 | 정지에 가까운 와이드, 제목 라벨 |
| 2. 단계 1…N | 각 15~20% | 단계마다 한 가지 변화만 | 과정 시각화: 같은 세계 안에서 카메라가 다음 지점으로 이동, 해당 요소만 강조 |
| 3. 연결 | 15% | 단계들이 이어진 흐름을 한 번에 | 줌아웃 + 흐름 화살표/경로가 순서대로 켜짐 |
| 4. 정리 | 10% | 핵심 문장 1개 | 정지 유지 |

규칙
- 한 단계 = 한 가지 움직임 + 라벨 1개. 단계 사이를 fade 로 끊지 않는다(세계는 하나).
- 순환 과정(물의 순환 등)은 마지막이 처음으로 이어지는 닫힌 카메라 경로로 만들면 루프 재생이 가능하다.
- 단계 번호·화살표 색은 강조색 하나로 통일.
- 추천 스타일: 01, 04, 07, 02. 추천 연출기법: 과정 시각화 + 단계적 등장 + 정보 강조.
